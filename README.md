# Git 练习仓库

这是我的第一个 Git 仓库，用来熟悉版本控制的基本操作。

## 我学会的命令

- `git init` —— 把一个普通文件夹变成 Git 仓库
- `git status` —— 查看当前有哪些文件被改动
- `git add` —— 把改动放进暂存区
- `git commit` —— 把暂存区的内容存成一个版本
- `git push` —— 把本地提交推到 GitHub
